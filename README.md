# GenAI-RAG-Evaluator

Production-ready Retrieval-Augmented Generation (RAG) pipeline built with LangChain, ChromaDB, and OpenAI, integrated with automated **RAGAS** evaluation metrics and a **Streamlit** user interface.

## 🚀 Features
- **Document Ingestion:** Automated chunking and vector embedding via ChromaDB.
- **RAG Generation:** Powered by GPT-4o with optimized prompt routing.
- **Automated Evaluation:** Evaluates pipeline outputs on Faithfulness, Answer Relevancy, and Context Precision using RAGAS.
- **Interactive UI:** Streamlit application for end-user querying and live performance metrics.
